# Related Instruction Patterns

Project Instruction Template v1.0 is a general-purpose template. It does not claim to replace or standardize host-specific instruction mechanisms.

Related public patterns include:

- **ChatGPT Projects** — project-specific instructions and project sources are separate contextual surfaces. See OpenAI Help: https://help.openai.com/en/articles/10169521-projects-in-chatgpt
- **AGENTS.md** — a plain-Markdown convention for coding-agent guidance, intentionally separate from human-facing README material. See https://agents.md/
- **OpenAI Codex AGENTS.md guidance** — Codex has its own discovery and precedence behavior for agent instruction files. See https://developers.openai.com/codex/guides/agents-md/
- **Cursor Rules** — persistent project rules can be scoped and version-controlled; Cursor recommends focused rules and concrete references. See https://cursor.com/docs/rules
- **Claude Code memory / CLAUDE.md** — Claude Code provides its own project-memory and instruction mechanisms. See https://code.claude.com/docs/en/memory

## Positioning

This repository borrows established ideas such as:
- concise project-level instructions;
- separation of instructions from reference material;
- scoped sources and methods;
- explicit acceptance criteria;
- versioned, reviewable project rules.

Its purpose is to provide a reusable cross-domain starting structure for evidence boundaries, baseline handling, authority separation, review discipline, completion semantics, and cross-session handoff.

No novelty, universal compatibility, or measured performance advantage is claimed. Host-specific documentation remains authoritative for loading, precedence, permissions, tools, memory, and enforcement behavior.
